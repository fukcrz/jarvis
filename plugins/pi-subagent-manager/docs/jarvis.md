# Jarvis 本地适配

基于上游 `pi-subagent-manager@1.6.1`，由仓库本地维护。

- 费用显示默认关闭；`costDisplay: "off"` 清除费用状态，设置菜单可选择 Off。
- 子代理模型请求透传根会话 `ownerSessionId`，用于模型组路由。
- 主题色不可用时，通知徽标降级为普通文字。
- 主动停止清除底层 abort 错误；暂停保留未收尾语义。
- 父线程结束后，异步孙线程结果补投根会话 mailbox。
- 通过当前会话的 `pi.events` 发送 `pi-subagent:live:v1`，数据为 `{ version: 1, thread: ThreadView }`。进度与用量按线程每 150ms 合并，其他事件立即发送。切换会话和关闭时清理待发计时器。
- 流式正文使用最近 1000 字更新当前进度；不发送完整子会话历史或思考正文。

实时事件只用于 UI，不写入 JSONL，不触发模型回合。Jarvis 在会话级事件总线上监听并复用 `tool.upsert` 更新已有卡片及详情；主模型回合结束不丢弃子代理卡片引用。重新打开会话时使用既有 registry 全量与增量记录恢复卡片状态。

## 兼容性

费用显示新增 `off` 配置值，保留已有显示模式；未显式配置时默认关闭，无需数据迁移。registry 落盘格式不变。新增事件使用独立频道；没有 Jarvis 监听者时事件被忽略，不与其他插件的工具或消息冲突。该本地包不通过已发布哈希自动覆盖，也不从 npm 自动更新。
