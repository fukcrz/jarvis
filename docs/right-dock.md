# 右侧停靠面板（侧聊 / 子代理）

## 结构

```text
时间线                                    ┌ [侧聊] [子代理 ①]  ✕ ┐
                                          ├───────────────────────┤
                                          │ 列表页 / 详情页        │
                                          └───────────────────────┘
                                             ↑ 拖这条边改宽
```

- 一个抽屉、两个 tab、一条宽度：`侧聊` 与 `子代理` 共用 `src/client/components/right-dock.tsx` 的外壳和拖拽手柄。
- 开关在会话顶栏：`SideChatToggle`（侧聊）、`SubagentToggle`（子代理，带运行中数量徽标）。两者都只是"打开面板并切到自己的 tab"，再点一次关闭。
- tab 选择记忆在 `localStorage["jarvis.right-dock.tab"]`，宽度记忆在 `localStorage["jarvis.side-chat.width"]`（280–720，双击分隔条复位 440，`←`/`→` 每次 16px）。

## 子代理面板

数据来源是当前会话时间线里的 `agent_spawn` / `agent_*` 卡片：插件 `pi-subagent-manager` 每 150ms 推一次线程快照，服务端 `src/server/subagent-view.ts` 解析成 `SubagentCallView`，客户端 `src/client/lib/subagent-panel.ts` 摊平成列表行。列表进度由事件推送，不轮询。

- **列表页**：`进行中` 在上（按开始时间），`已结束` 在下（默认最近 5 条 + 「查看全部」）。每行两行文本：状态点 + 类型 + 耗时 / 当前动作（单行省略）。层级按线程路径缩进。
- **详情页**分「概览 / 输出」两个子 tab。概览是状态、模型、thinking、tokens、费用、当前动作、结果、任务；输出是这个线程自己的过程，只读。左上「返回」或 Esc 回列表，右上「在时间线中定位」。
- **输出的实时部分**由插件从子会话事件增量推出（通道 `pi-subagent:stream:v1`，每线程 200ms 一批），服务端按线程保留最近 200 条、最近 32 个线程，经 `subagent.stream` 推给前端，并随 runtime 接口回放。刷新页面不丢，进程重启后清空。
- **输出的历史部分**：任何状态的线程打开「输出」时，都通过父会话下的只读线程历史接口读取已落盘内容。接口只解析 JSONL，不创建 AgentSession 或加载扩展，并校验 rootId/threadPath 归属、过滤继承上下文。按 200 条硬分页，可继续加载更早输出；读取失败可重试。
- 历史与实时使用相同的 assistant timestamp + contentIndex / toolCallId 作为条目 ID。首屏与更早页均前插，已经收到的 live 条目覆盖同 ID 历史，避免请求期间的较旧快照覆盖新输出。正文、思考、工具输出不另加 4k/2k 裁剪。此简化流不承诺展示工具图片。
- 耗时每秒跳一次（仅在有进行中线程时开 timer），当前动作跟着 live 事件更新；行高固定，状态变化只换颜色和图标。

## 边界

- 只表达当前会话；跨会话要看左侧会话列表的状态点。
- 只在桌面端提供。移动端仍用编辑器上方的子代理状态胶囊（`SubagentStatus`）。
- 输出视图不提供输入、停止、暂停或重新执行；历史读取失败可重试。
